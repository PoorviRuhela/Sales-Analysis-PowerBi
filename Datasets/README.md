# 📊 Sales Analysis Dashboard — Datasets

## 📌 About the Dataset

This folder contains the source datasets used to build the **Sales Analysis Dashboard** in Microsoft Power BI.

These datasets help analyze sales performance, profit, product categories, order trends, payment methods, and state-wise sales.

## 📂 Files Included

### 1. Orders.xlsx
Contains order-related information used to analyze sales transactions and order performance.

### 2. Details.xlsx
Contains additional sales details used to analyze product categories, quantities, sales, profit, and other business metrics, depending on the available columns.

## 🎯 Purpose of the Data

The datasets are used to:

- Analyze overall sales and profit.
- Understand product category performance.
- Identify monthly sales trends.
- Compare sales across states.
- Analyze payment methods.
- Create interactive charts, KPIs, and filters in Power BI.

## 🛠️ Tools Used

- **Microsoft Excel** — To store and review the source data.
- **Microsoft Power BI** — To transform, analyze, and visualize the data.

## 🔗 Project Dashboard

The datasets are connected to the Power BI dashboard to generate meaningful business insights and support data-driven decision-making.

## ⚠️ Note

The analysis depends on the columns and records available in the source files. If you download these datasets, you may need to update the data source paths in Power BI.
