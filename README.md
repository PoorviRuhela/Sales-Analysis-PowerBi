# 📊 Sales Analysis Dashboard | Power BI

An interactive sales analytics dashboard built using **Microsoft Power BI** to analyze sales performance, profitability, product categories, payment methods, monthly trends, and state-wise sales.

## 📌 Project Overview

The Sales Analysis Dashboard transforms sales data into meaningful visual insights to help understand business performance and identify sales trends.

The dashboard presents key performance indicators (KPIs) and interactive visualizations in a single report, making it easier to explore different aspects of sales data.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Monitor total orders and quantity sold.
- Compare sales performance across product categories.
- Understand monthly sales trends.
- Analyze sales distribution by payment method.
- Compare sales performance across states.
- Explore data using interactive filters and a reset button.

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** — Dashboard development and visualization
- **Power Query** — Data preparation and transformation, where applicable
- **Excel / CSV** — Source data, depending on the dataset format

## 📈 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

| KPI | Purpose |
|---|---|
| Total Sales | Measures overall sales revenue |
| Total Profit | Measures profit generated |
| Total Quantity | Tracks total quantity sold |
| Total Orders | Shows the number of orders |

## 📊 Dashboard Features

- **Sales Overview:** Displays key sales performance indicators.
- **Category Analysis:** Compares sales, profit, and quantity across product categories.
- **Monthly Trend Analysis:** Visualizes changes in sales over time.
- **Payment Method Analysis:** Shows the distribution of sales by payment method.
- **State-wise Analysis:** Compares sales across different states.
- **Interactive Filters:** Enables users to explore specific categories and segments.
- **Reset Button:** Returns the dashboard to its default filter state when configured.

## 💡 Business Questions Explored

This dashboard helps explore questions such as:

1. What is the overall sales and profit performance?
2. Which product categories contribute most to sales?
3. How do sales change from month to month?
4. Which payment methods account for the largest share of sales?
5. Which states generate the highest sales?
6. How do the dashboard's results change when filters are applied?
